# Taras Villa Lonavala

Villa brochure with an enquiry form that sends the guest's details to the owner on WhatsApp (+91 72087 13559).

Live site: https://YOUR-USERNAME.github.io/REPO-NAME/

## Files
- `index.html` - the whole tool
- `img/` - villa photos and decoration
- `og.jpg` - picture shown when the link is shared

## Change the WhatsApp number
Open `index.html`, search for `const WA =` and replace the number (country code first, no + or spaces).
